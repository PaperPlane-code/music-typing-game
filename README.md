# 字间 · 歌词打字游戏

用打字，让一首歌慢慢发生。当前版本：**1.5.0 · Windows 浏览器启动版**。

输入正确的一小段歌词，就播放对应的演唱；播放期间可以持续提前输入，已经写好的歌词按歌曲顺序排队播放。前奏、间奏和尾奏自动播放，制作人员信息无需输入。

## 开始游玩

1. 完整解压 `Zijian-1.5.0-Browser-Windows-x64.zip`，保留全部文件与目录。
2. 双击 **Zijian.exe**。它会启动本机服务并自动打开系统默认浏览器，沿用正常用户配置。
3. 在网页选择一份音乐文件，以及同一录音版本的 **LRC 歌词**或**字间歌曲 JSON**。
4. 确认有权使用所选素材，点击“检查并试听”；确认匹配后点击“用这首歌开始”。
5. 点击“开始写这首歌”，照着歌词输入。中文请使用中文输入法输入汉字。

音乐文件最大 **128 MB**、最长 **15 分钟**；支持 MP3、WAV、FLAC、M4A、AAC、OGG、OPUS，具体编码是否可用取决于浏览器。歌词文件最大 **1 MB**。解码失败时可尝试 MP3 或 WAV，或检查文件是否损坏。

单独一个音乐文件通常不包含可靠的逐句歌词时间轴。本版本不自动听写歌词，也不自动替导入的音乐匹配联网歌词；需要用户同时提供 LRC 或 JSON。

游玩期间保留启动器窗口，关闭它即可停止服务。如果网页没有自动打开，使用启动器的“复制地址”，粘贴到平时使用的浏览器。首选端口为 `52731`，占用时会另选端口，以窗口中的实际地址为准。

系统要求：Windows 10/11 x64、系统自带的 .NET Framework 4.x，以及支持 Web Audio 的现代浏览器。发布包自带运行环境，不需要安装 Node.js。不要只复制 EXE；`runtime/`、`app/`、`web/` 必须保留。

## 歌词文件格式

LRC 每行以时间戳开头，建议采用 UTF-8 编码，也兼容常见 GBK 和带 BOM 的 UTF-16。下面是用于说明格式的原创短句，时间须根据自己的音频填写：

```text
[ti:我的歌曲]
[ar:我的名字]
[00:02.00]你好，今天
[00:06.00]慢慢写下下一句
[00:10.00]
```

下一行时间戳通常作为上一句结束点，空时间戳可标明演唱结束或间奏。作词、作曲、制作人等信息会跳过；相邻歌词之间未覆盖的音频会作为自动播放区间。支持 `[offset:毫秒]` 和一行多个时间戳。请先试听，确保歌词和录音版本一致。

JSON 使用字间的 `schemaVersion: 1` 格式：

```json
{
  "schemaVersion": 1,
  "title": "我的歌曲",
  "subtitle": "我的名字",
  "segments": [
    { "displayText": "你好，今天", "inputText": "你好，今天", "start": 2, "end": 6 },
    { "displayText": "慢慢写下下一句", "inputText": "慢慢写下下一句", "start": 6, "end": 10 }
  ]
}
```

`start`、`end` 单位为秒，各段必须顺序排列、互不重叠，且不超过实际音频时长。每段展示文字应与输入目标一致。JSON 中的音频网址不会被加载，始终使用本次选择的本地音乐文件。最多支持 5000 个歌词段落。

ZIP 中 `examples/` 提供上述两种歌词模板，**不包含配套歌曲音频**。

## 输入与播放

- 未输入的字符为暗灰色，正确字符逐个变亮，错误位置显示黄色提示；退格修正后可继续。
- 标点和空格可以省略；中文输入法选字期间不判错。
- 提前输入不限制句数，演唱按顺序播放，不会叠加。
- 可以暂停、继续、重开或重新导入音乐；取消新导入可回到当前歌曲，重新选用后从第一句开始。
- 切换到后台自动暂停；回到页面后点击继续。
- 粘贴允许体验流程，该局会标记为辅助练习。
- 刷新或关闭网页后，需要重新选择音乐和歌词，不自动恢复本局进度。

## 本地处理与隐私

**导入的文件只在当前浏览器内读取、解码和播放，不上传到本机服务、远程服务器或其他玩家，也不复制到游戏目录。** 选择文件的步骤是本地导入，并非将音乐公开上传。

浏览器本地保存音量和最近一次非辅助练习结果，不保存导入音频。启动器日志与临时状态默认在当前用户 `LocalAppData/Zijian/Browser`，不可写时回退到游戏目录的 `data/`。本项目没有账号、排行榜或向作者上报成绩的统计服务。
