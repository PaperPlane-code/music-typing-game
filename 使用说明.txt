字间 1.5.0 · 浏览器启动版

完整解压整个文件夹后，双击 Zijian.exe。服务就绪后通过 Windows URI 激活接口打开系统默认浏览器，沿用该浏览器正常的用户配置。
不再创建或启动字间专用浏览器配置，也不复制浏览器用户数据。
启动器收到首页就绪回报后，提示导入歌曲；导入的音频解码完成后才显示歌曲就绪。
若网页没有打开，点击“复制地址”，将完整地址粘贴到常用浏览器地址栏。
启动器只保留状态、实际游戏地址和“复制地址”，关闭窗口即可停止服务。
游玩期间保留启动器窗口；关闭浏览器标签不会自动停止服务。
EXE 版首选端口 52731，端口占用时以窗口显示的地址为准；5173 是开发版端口。
无需安装 Node.js 或 Electron，使用电脑已安装的默认浏览器。
不包含内置歌曲。请选择自己的音乐文件及配套 LRC / JSON，全部在浏览器本地处理；在线找歌需要网络。详细使用及不盈利说明见 README.md。
所有 runtime、app、web 文件夹都必须保留，不能只复制 EXE。
Windows 10/11 x64；启动器使用系统自带 .NET Framework 4.x。
日志默认在当前用户 LocalAppData/Zijian/Browser，不可写时改用游戏目录的 data 文件夹。

第三方软件许可见 THIRD-PARTY-NOTICES.txt 和 licenses/。转发程序时请保留这些声明及 runtime/LICENSE-node.txt。
FILES.json 记录发布文件及 SHA-256；ZIP 的 SHA-256 校验文件随压缩包另附。
